# Quantum Rift 0.3.4.4

Public release: **0.3.4.4**. The source package and release tag retain **3.4.4** and **v3.4.4**, respectively.

## Index survey groups

Neutral Index machines no longer park at fixed points once they reach their
worksite. The parent machines circle the worksite slowly as one ring, and their
drones sweep around them, so the group keeps its spacing while staying in
motion. Deployed Looms follow the ring at survey speed. Machines that are
defending marked work still break off to fight, and split Trident blades still
return to rejoin.

## Blue cockpit chat

The comms console now shows the same blue display glass as the other cockpit
panels. Previously its frame artwork painted a grey centre over the glass, so
only the history strip looked blue. Expanding chat history keeps the console
blue; the parked "History projected above" notice no longer uses the older teal
finish. The function dock and utility panels use the same unfilled frame.

## Captain portraits

The Profile tab's portrait choices now load with the current artwork version
when the tab opens, like the large preview. Portrait files follow the same
version-checked caching as ship and outfit artwork, so a browser that cached a
broken copy from an earlier build fetches a fresh one.

## Updating

Close the old server before starting the new copy. Back up and preserve existing
Solo and friend-game save folders. Download **Quantum-Rift-latest.zip**, extract
it, and follow the [README](../README.md) and its runtime instructions. The game
remains in beta. The beta Solo save generator catalog matches version 3.4.4.
