# Quantum Rift 0.4 — Delta Quadrant Stable Beta

## Changes

- Learn the cockpit with a menu tour and ten-slide briefing. Skip either guide or replay the introduction from HELP. Control hints use your saved key bindings.
- Open your captain profile with CAPTAIN and ship details with INFO. REFINE opens Dredge processing; the thruster-pod EJECT button opens the quit menu. Escape still works.
- Follow the tour through both cockpit button rows from left to right.
- Keep the square system map at a maximum of 350 CSS pixels, even in a wider sidebar. The menu below it fills available space without a separate height slider.
- Simplify three towing labels without changing transfers or their acceptance requirements.

## Updating

Close the old server and back up the complete Solo or friend-game save folder. Extract the new download into a separate folder and follow the [README](../README.md). Keep the old installation and backup until you have checked your captain.

Native online hosts should follow the [Nakama hosting guide](NAKAMA.md). The optional save generator remains Solo-only; online servers do not accept imported Solo saves.

The public beta label is **0.4**; the npm package version is `0.4.0`. This update does not change the network protocol or save schema.
