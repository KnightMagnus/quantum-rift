# Quantum Rift 0.6 Unstable Beta

This is an unstable beta. Back up your complete Solo or friend-game save directory before updating, and extract the download into a separate folder after stopping the old server.

## Changes

- Continue the story with new missions, objectives and choices.
- Explore new regional scenery, planetary layouts and ship artwork.
- Mission progress and objectives are saved between sessions.

## Download and play

Download `Quantum-Rift-latest.zip` from the release assets; the source-code archives are not the complete game download. See the [README](../README.md) for launch instructions and requirements.

Keep `package-manifest.json` and `SHA256SUMS` with the ZIP for verification. The optional save generator remains Solo-only.

Automated checks cover story progression, saved objectives, artwork loading and packaged startup. They do not establish balance across every choice or compatibility with every existing save. Physical touch devices, gamepads and screen-reader compatibility have not been verified for this release.
