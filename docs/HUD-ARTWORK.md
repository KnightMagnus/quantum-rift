# HUD artwork

The cockpit uses these icon variants: Combat A, Towing B, Fleet A, Drones A,
Hailing/Comms B and Processing C. Mining uses the spiral-drill artwork.

The cockpit has a compact dark-steel console, an integrated right-edge Tray,
Pixelify Sans typography and digital viewscreens. Artwork is in `client/assets/hud/`.
Hailing uses its authoritative handlers from the cockpit icon grid.
