# Quantum Rift 0.3.5

Public release: **0.3.5**. The source package and release tag retain **3.5.0** and **v3.5.0**, respectively.

## Cockpit controls

The login console uses the same blue display glass, header and sculpted hull
frame as the in-game cockpit. Landed-service buttons sit in a larger row across
the top of the port panel, above the world heading.

A gold JUMP button appears in flight and shows the current jump key. It becomes
available when a destination system is plotted. Settings → Display can move it
from the bottom-right to the bottom-left corner of the viewscreen. J remains the
default jump key, and custom jump bindings still work.

## Personal Stations

Your own Personal Station always grants docking clearance, even when the local
faction is hostile. The same owner clearance applies to refinery access and
motherlode delivery; docking control no longer asks you to buy an access pass
for your own station.

Visiting another captain's Personal Station shows its owner's name and a
**Guest Dock** label. Guests can use OVERVIEW, TRADE, JOBS and their own CREW.
The owner's docks, hangar, refinery and other station internals remain private.
Ordinary faction clearance still applies to visitors.

## Updating

Close the old server before starting the new copy. Back up and preserve existing
Solo and friend-game save folders. Download **Quantum-Rift-latest.zip**, extract
it, and follow the [README](../README.md) and its runtime instructions. The game
remains in beta. The beta Solo save generator catalog matches source version
3.5.0 and remains Solo-only.
