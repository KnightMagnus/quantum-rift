# Quantum Rift 0.7 Unstable Beta

This is an unstable beta. Stop the old server and back up your complete Solo or friend-game save directory before updating. Extract the new download into a separate folder.

## Changes since 0.6

- Updated arrival scenes, Sol visuals and generated planetary layouts.
- More varied regional traffic and ship artwork.
- New Freefolk and Unsworn hull designs.
- Consistent unstable-beta labels in the game and release package.

## Download and play

Download `Quantum-Rift-latest.zip` from the release assets. The source-code archives are not the complete game download. Follow the [README](../README.md) for launch instructions and runtime requirements.

Keep `package-manifest.json` and `SHA256SUMS` with the ZIP for verification. The optional save generator remains Solo-only.

This release does not establish compatibility with every existing save or balance across every encounter. Physical touch devices, gamepads and screen-reader compatibility have not been verified for this release.
