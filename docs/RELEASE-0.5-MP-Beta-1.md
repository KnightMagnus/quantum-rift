# Quantum Rift 0.5 MP Beta 1

## Changes

- Reduce repeated processing when sending multiplayer system updates.
- Keep world simulation and station processing running when a client notification fails.
- Add downloadable browser performance reports for investigating slowdowns.

## Updating

Close the old game server, back up your complete Solo or friend-game save folder, and extract the new download into a separate folder. Follow the [README](../README.md) for launch instructions.

The optional save generator remains Solo-only. Physical touch devices, gamepads and screen-reader compatibility have not been verified for this release.
